Regime-aware decision systems can route predictions through specialized experts, yet a well-separated latent state does not establish a valid causal mechanism. We develop the Causal Macro Transmission Framework (CMTF) as an identification-aware interface between proposed economic mechanisms, versioned evidence, and expert eligibility. A reference router checks declared identification status, provenance, numerical validity, and evidence availability before assigning normalized expert weights or abstaining. We evaluate a separate synthetic diagnostic that isolates confounding and regime-observation misspecification. Four scenarios, each with 200 independent seeds, compare pooled regressions, hard and soft filtered routing, and an oracle-state baseline over 2,000 training and 1,000 test observations. With observed confounding and a correctly specified observation model, soft routing reduces mean squared structural-coefficient error from 1.025 for pooled adjusted estimation to 0.373. Reversing the observation-to-regime mapping at test time raises soft-routing error to 2.890, above the unchanged pooled error of 1.025. With hidden confounding, even oracle-state routing retains error of approximately 1.004. These results separate state uncertainty from causal identification: improved routing cannot remove an omitted common cause, and correct local estimates can be misapplied when state semantics change. The contribution is an executable evidence contract and a reproducible failure diagnostic, not an end-to-end causal discovery system or evidence of trading profitability.
